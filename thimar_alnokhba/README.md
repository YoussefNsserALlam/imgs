# ثمار النخبة — دليل الإعداد

## 1) تجهيز Google Sheet
أنشئ شيت وسمِّ التبويب الأول `Products` وضع في الصف الأول هذه العناوين بالإنجليزية بالضبط:

id | name | price | old_price | image | images | category | weight | description | available | badge

- id: رقم أو كود فريد لكل منتج (1، 2، 3...)
- image: رابط الصورة الرئيسية (رابط مباشر)
- images: صور إضافية للصفحة الداخلية مفصولة بفاصلة
- available: اكتب no أو لا لإخفاء المنتج. لحذفه احذف الصف
- old_price و badge اختياريان (سعر قبل الخصم / شارة مثل "خصم")

ثم: مشاركة (Share) ← أي شخص لديه الرابط ← مشاهد (Viewer).

## 2) الربط
انسخ معرّف الشيت من الرابط:
docs.google.com/spreadsheets/d/**هذا_الجزء**/edit
وضعه في `app.js` داخل CONFIG.SHEET_ID، وضع رقم واتساب في CONFIG.WHATSAPP (بالصيغة الدولية بدون +).

## 3) الرفع
ارفع المجلد كاملاً على Netlify أو Vercel أو GitHub Pages أو أي استضافة. التعديلات على الشيت تظهر مباشرة بعد تحديث الصفحة.

ملاحظة: افتح الموقع عبر استضافة أو Live Server وليس بالنقر المزدوج على الملف، حتى يعمل تحميل الشيت.
